# COMP9517-Forest-Segmentation-Project
A team research project done with other university students on the performance of different machine learning algorithms in segmenting dead trees using aerial imagery.

A report of our research as well as the code have been left in this repositry.

The data used for this project is too big for this repositry. Instead I will leave a link.

Link to data: https://www.kaggle.com/datasets/meteahishali/aerial-imagery-for-standing-dead-tree-segmentation
